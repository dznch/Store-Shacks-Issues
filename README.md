# Store Shacks — Issues

This repository is the bug tracker for **Store Shacks**, a NeoForge mod for Minecraft 1.21.1.
It only holds reports — there is no code here.

## Before you report

- Make sure you are on the **latest version** of Store Shacks.
- Search the [existing issues](../../issues) — your problem may already be reported.
- Try to reproduce it with only Store Shacks and its dependencies installed. If it only happens together with another mod, say which one.

## How to report

Open a [new issue](../../issues/new/choose) and pick a template:

- **Bug report** — something works wrong or looks wrong.
- **Crash report** — the game or server crashes.
- **Suggestion** — an idea or a change you would like to see.

Please include:

- Store Shacks, NeoForge and GeckoLib versions
- whether it happens in singleplayer, on a server, or both
- steps to reproduce
- logs or the crash report, uploaded to [mclo.gs](https://mclo.gs) — paste the link instead of the whole file
- screenshots or a short video, if it is visual

One problem per issue, please. Thank you for helping make the mod better!
